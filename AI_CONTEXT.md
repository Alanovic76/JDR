# AI_CONTEXT — JDR

## Projet

JDR est un jeu de rôle 2D développé en Rust avec Bevy.

## État actuel

Prototype Niveau 01 :
- déplacement du joueur
- carte en grille
- murs et collisions
- sortie
- PNJ décoratif
- HUD minimal

## Règles importantes

1. Ne pas supprimer une fonctionnalité existante sans raison.
2. Lire ce fichier et `ARCHITECTURE.md` avant de modifier le projet.
3. Faire des modifications petites et ciblées.
4. Ne pas réécrire tout un module pour une petite correction.
5. Garder le code compilable.
6. Tester avec `cargo check` avant de considérer une modification terminée.
7. Mettre à jour la documentation si l'architecture change.
8. Les futures IA doivent privilégier les modules indépendants.
