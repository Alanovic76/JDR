# JDR — Étape 2b

- 4 à 6 rencontres sont placées aléatoirement au lancement du niveau.
- Les cases de rencontre sont totalement invisibles.
- En marchant sur une case, le combat démarre immédiatement.
- Le monstre est choisi aléatoirement parmi Gobelin, Renard, Loup et Hobgobelin.
- Aucun choix de monstre n'est demandé au joueur.
- ESPACE lance le D20 pendant le combat.

Après extraction dans `~/JDR` :

```bash
cargo check
cargo run
```
